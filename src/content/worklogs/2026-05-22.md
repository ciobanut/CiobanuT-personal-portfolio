# 22 May 2026

Added behavora script-install verification with a countdown, wired it into the onboarding checklist, and pre-filled login from query parameters.

## Projects

### behavora (journey-predictor-api)

**Script verification.** Added a check that verifies the widget script is installed correctly (+149), with a countdown in the waiting state of the verify-script component (+35/−7) and a countdown for the whole verification process (+60/−46). The progress bar now uses the timeout from the Livewire variable.

**Onboarding.** Integrated `verify_script` with the onboarding checklist (+91/−59) and fixed step 6 of the checklist (+115/−106).

**Login UX.** Pre-filled the login form from query parameters (+27/−5).

### All changes

- Added verify-script-installed check (+149)
- Added countdowns for the verification process
- Integrated verify_script into onboarding checklist
- Fixed onboarding step 6
- Pre-filled login form from query params

## Lessons

Self-serve install verification turns a support request ("is it working?") into a product feature — the countdown makes the async check feel deterministic.
