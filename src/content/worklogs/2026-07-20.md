# 20 Jul 2026

Implemented visitor country detection on behavora with MaxMind GeoLite2 and a searchable multi-country selector in scoring rules, and added provider-aware avatar fallback on MyPrivateOrder.com.

## Projects

### behavora (journey-predictor-api)

**Country detection.** Implemented visitor country detection via MaxMind GeoLite2 (+534) — the tracking pipeline reads the visitor's IP and resolves a country, with documentation added (+175). `VisitorSessionsTable` now shows the country label with an improved geo tooltip.

**Country selector in scoring rules.** Added a searchable select of all countries in the Add Rule modal (+457) when the signal is country-based, plus multi-country selection with flag emoji support. Country display was cleaned up to render as individual badges with correct emoji flags.

**Banner threshold.** Updated the banner show-threshold default value and improved the modal display.

### myprivateorder.com

**Avatar fallback.** Implemented fallback logic for the avatar (+382): if the user has a provider, the provider avatar is used — otherwise the user avatar. Built a reactive avatar component, updated its usage in navigation and settings, improved the update-avatar layout, and refreshed the header avatar after upload. Configured upload limits in the Docker setup.

### All changes

- Added MaxMind GeoLite2 visitor country detection + docs
- Added searchable country select and flag-emoji multi-select in scoring rules
- Displayed country labels/badges in visitor sessions table
- Added provider-aware avatar fallback and reactive avatar component
- Configured avatar upload limits in Docker
- Updated banner show-threshold default and modal

## Lessons

Geo data is infrastructure you bolt on, not a core feature: the tracking payload stays IP-only, and a resolver layer turns IP into country at the boundary.
