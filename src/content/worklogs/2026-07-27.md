# 27 Jul 2026

Replaced behavora's hard-coded `SignalKey` enum with a dynamic `Feature` model for scoring, added `SignalPreset` persistence, and did a portfolio pass: design docs, dark mode, and a Latest Blog Posts section.

## Projects

### behavora (journey-predictor-api)

**Dynamic Feature model.** The scoring engine's `SignalKey` enum was replaced by the dynamic `Feature` model (+547/−206) — signals are now data, not code. Renamed feature names for clarity (dropped the "If the" prefix) and consolidated overlapping signals into canonical ones. Added descriptions and hints for the new visitor signals, and filtered feature roles to boolean data types in the weights UI.

**SignalPreset model.** Implemented the `SignalPreset` model with migration and tests (+334) so scoring presets can be persisted and managed as data.

**Scoring robustness.** Handled scoring engine errors and updated the scoring breakdown structure so a failure surfaces cleanly instead of breaking the breakdown view.

### astro-portfolio-website

**Design docs.** Added configuration and design documentation (1,206 lines) for the portfolio.

**Homepage + dark mode.** Added a `LatestBlogPosts` component to the homepage and extended dark mode support across components and layouts. Replaced the Typesense blog post image and removed the outdated Laravel policies article.

### All changes

- Replaced `SignalKey` enum with dynamic `Feature` model for scoring (+547/−206)
- Renamed features for clarity and consolidated overlapping signals
- Added signal metadata descriptions/hints; filtered weights to boolean roles
- Added `SignalPreset` model, migration and tests
- Handled scoring engine errors; updated breakdown structure
- Added portfolio design/config docs
- Added `LatestBlogPosts` homepage component
- Extended dark mode support across components and layouts
- Removed outdated Laravel policies article

## Lessons

Moving from enum to database-driven features is the right call once rules become user-configurable: the scoring engine reads the same rows the UI edits, so there is one source of truth.
