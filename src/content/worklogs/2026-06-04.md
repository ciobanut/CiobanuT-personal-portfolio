# 4 Jun 2026

Added a job-details modal with navigation and polling to auto_sender, simplified job constructors, and installed laravel-echo + pusher-js for behavora websockets.

## Projects

### auto_sender

**Job details modal.** Implemented a job-details modal with navigation for analyzed jobs (+178) and streamlined job-detail extraction with improved HTML cleaning (+41/−28).

**Polling.** Added polling for job analysis, fetching, generation and sending stages (+37/−29) so the UI stays current without manual refresh.

**Cleanup.** Simplified job constructors by removing queue assignment (+5/−13), fixed a multiple-root Livewire component, and fixed the login/register/forgot-password forms.

### behavora (journey-predictor-api)

**Websockets.** Installed `laravel-echo` and `pusher-js` (+111/−28) as the foundation for realtime banner events.

### All changes

- Added job-details modal with navigation
- Added polling across job stages
- Streamlined job-detail extraction/HTML cleaning
- Simplified job constructors
- Fixed Livewire multiple-root and auth forms
- Installed laravel-echo + pusher-js

## Lessons

Polling is the pragmatic realtime for a job pipeline before websockets justify themselves; the stage-scoped polling keeps requests cheap.
