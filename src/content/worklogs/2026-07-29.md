# 29 Jul 2026

Cleaned up URL management and started Shopify integration.

## Projects

### myprivateorder_com

- Extracted 9 hardcoded URL constants into a dedicated `UrlConfig` class — now all API endpoints are defined in one place with proper documentation.
- Integrated Shopify API for order syncing: orders placed on Shopify are now automatically imported into the system.
- Added webhook handling for Shopify order creation events.

### All changes

- Created UrlConfig class with named constants
- Replaced all inline URLs with UrlConfig references
- Added Shopify OAuth flow
- Implemented order import from Shopify
- Added webhook endpoint for real-time order sync

## Lessons

When integrating with external APIs, always encapsulate the endpoint URLs in a config class from the start. It makes testing (mocking) and maintenance significantly easier.
