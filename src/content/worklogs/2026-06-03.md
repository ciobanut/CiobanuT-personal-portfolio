# 3 Jun 2026

Grouped behavora's banner settings into logic categories, added scroll/time eligibility guards, and documented the full banner decision flow with diagrams.

## Projects

### behavora (journey-predictor-api)

**Settings reorganization.** Grouped banner settings into logic categories (+582/−129) so related configuration reads as one unit.

**Eligibility signals.** Implemented `min_scroll_percent` and `min_time_on_page` in `BannerEligibility` (+120) — a banner only shows once the visitor has scrolled or spent enough time.

**Docs.** Added diagrams of the banner decision flow (+328).

**Fix.** Improved layout header spacing on small screens.

### All changes

- Grouped banner settings into logic categories
- Added min_scroll_percent and min_time_on_page to BannerEligibility
- Added banner decision-flow diagrams
- Fixed header spacing on small screens

## Lessons

Engagement gates (scroll depth, time on page) are eligibility concerns, not display rules — putting them in `BannerEligibility` keeps the decision flow single-threaded.
