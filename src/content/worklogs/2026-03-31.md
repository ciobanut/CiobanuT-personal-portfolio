# 31 Mar 2026

Fixed a long-page save error in Bloop-landing's Filament admin, added a zero-downtime deployment script to MyPrivateOrder.com, and added expo-dev-client to the React Native app.

## Projects

### Bloop-landing

**Long-page save fix.** Fixed an error when saving a long page with many blocks in the Filament admin (+363/−62). Adjusted the cookie-consent banner max width, fixed language-tab identifiers in `WebsiteSettings`, added an email link and removed background elements from the show page, and added a favicon to the admin config.

### myprivateorder.com

**Zero-downtime deploy.** Enhanced the deployment script for zero-downtime updates and improved provider aliases (+417/−139), then reverted the CI/CD back to no-zero-downtime (+149/−178) after evaluating. Enhanced `ProviderResource` and `ReviewResource` forms with custom option labels.

### react-native-expo

**Dev client.** Added `expo-dev-client` and enhanced `ArrivalMapCard` markers (+166/−19).

### All changes

- Fixed long-page save error in Filament admin
- Added (then reverted) zero-downtime deploy script
- Added custom option labels to provider/review forms
- Added expo-dev-client; enhanced map markers

## Lessons

Zero-downtime deploys are a deliberate trade — the script was built and evaluated, then reverted when the operational cost wasn't worth it. That's a decision, not a failure.
