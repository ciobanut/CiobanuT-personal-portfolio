# 10 May 2025

Integrated Typesense into the MyPrivateOrder search and tuned its CORS and API key environment.

## Projects

### myprivateorder.com

**Typesense.** Implemented Typesense (+9) and replaced the Livewire search with Typesense (+3/−3). Passed Typesense variables via the command line (+9/−4) and set `TYPESENSE_API_KEY_FILE` to the Docker secret (+5/−3).

**CORS.** Tuned Typesense CORS (disabled then enabled via env) so browser search works from the app domain.

### All changes

- Integrated Typesense into search
- Passed Typesense env via command line
- Tuned Typesense CORS

## Lessons

Typesense CORS is the classic browser-blocker — the back-and-forth env commits show the toggle is the crux of search working from the page.
