# 17 Jun 2026

Added a Position Presets sector for simplified GrapesJS positioning, removed leftover test blocks, and corrected the banner-visible check to use `displayed_at`.

## Projects

### behavora (journey-predictor-api)

**Position Presets sector.** Added a Position Presets sector for simplified positioning in GrapesJS (+260) — common placements as one-click presets.

**Test cleanup.** Removed GrapesJS blocks created earlier for testing purposes (+1/−164).

**Show-timing fix.** `bannerIsShown` now checks `displayed_at` instead of `delivered_at` to decide whether a banner should display — the intended semantic is "has it actually been shown", not "has it been delivered".

### All changes

- Added Position Presets sector (+260)
- Removed testing-only GrapesJS blocks
- Changed `bannerIsShown` to check `displayed_at`

## Lessons

`delivered` vs `displayed` are easy to conflate, and the distinction matters for frequency capping — the fix aligns the guard with the actual event that should gate re-display.
