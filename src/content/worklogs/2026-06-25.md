# 25 Jun 2026

Moved behavora's dismissal options into the GrapesJS editor as Livewire variables, shipped client-side remember-dismiss, and stabilized the deploy workflows.

## Projects

### behavora (journey-predictor-api)

**Dismissal options.** Added Dismissal options to the GrapesJS editor as Livewire variables sent to the widget (+42/−10), and removed the old admin-side dismissal options (close-on-outside-click, close-on-esc, remember — −220) since the editor now owns them.

**Position presets.** Renamed `POSITION_PRESETS_SECTOR` to `BANNER_SETTINGS` and removed unused setup properties (+2/−49).

**Deploy workflows.** Fixed the production deploy (removed a needless `git checkout`), added the `storage:link` command to both prod and dev deploys, and updated `VITE_REVERB_APP_KEY` for prod.

### journey-predictor-client

**Remember-dismiss.** Implemented remember-dismiss functionality for server-rendered banners (+382/−12) — a dismissed banner stays dismissed across visits.

### All changes

- Moved dismissal options into GrapesJS editor as Livewire variables
- Removed legacy admin dismissal options (−220)
- Renamed position preset sector to BANNER_SETTINGS
- Fixed prod/deploy workflows; added storage:link; updated REVERB key
- Implemented remember-dismiss on the client

## Lessons

Configuration belongs where it's edited: moving dismissal rules into the GrapesJS editor made the admin sidebar redundant, and the removal commit (−220) kept the surface honest.
