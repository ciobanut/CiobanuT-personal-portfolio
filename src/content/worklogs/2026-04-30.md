# 30 Apr 2026

Enhanced behavora tracking with total time spent and last-journey data, added a user actions dropdown, and extended tracking fields.

## Projects

### behavora (journey-predictor-api)

**Tracking enhancement.** Added total time spent and last journey tracking (+237/−60) so a session carries aggregate engagement alongside its event stream.

**Tracking fields.** Updated tracking fields to include `page_description` and `canonical_url`, removing obsolete fields (+14/−52).

**Account UI.** Moved user actions (account settings and logout) into a dropdown (+18/−14).

### All changes

- Added total time spent and last-journey tracking
- Added page_description and canonical_url tracking fields
- Moved account settings/logout into a user dropdown

## Lessons

Session aggregates (total time, last journey) make dashboard queries cheap — the values are computed at ingest and stored, not derived per request.
