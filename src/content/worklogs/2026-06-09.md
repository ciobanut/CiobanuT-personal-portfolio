# 9 Jun 2026

Reversed cookie-consent logic so GTM always loads on MyPrivateOrder.com, broadcast a `BannerPredicted` event with banner details, and added debug size reporting to banner rendering.

## Projects

### myprivateorder.com

**GTM consent.** Reversed the cookie-consent logic: GTM now always loads from the start (+147/−7) instead of waiting for consent, trading consent-gating for analytics continuity.

### behavora (journey-predictor-api)

**BannerPredicted event.** Broadcast a `BannerPredicted` event with banner details when `sendBanner` runs (+18), so downstream listeners get the full banner context.

**Render debugging.** Enhanced banner rendering with debug size reporting and improved layout handling (+198/−6).

**Fix.** Aligned spaces in a Blade file (+151/−173).

### All changes

- Reversed cookie consent: GTM always loads
- Broadcast BannerPredicted event with banner details
- Added debug size reporting to banner rendering
- Fixed Blade whitespace alignment

## Lessons

Consent toggles have product consequences beyond law — loading GTM unconditionally changed the site's whole analytics baseline, and it was a deliberate reversal, not a revert.
