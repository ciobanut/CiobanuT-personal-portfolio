# 10 Jul 2026

Added behavora's `SessionFeatureComputer` service to compute and persist behavioral feature values, wired it into the prediction strategy, and re-labeled the feature catalog.

## Projects

### behavora (journey-predictor-api)

**SessionFeatureComputer.** New service (+135) that computes behavioral feature values for a session and persists them, so feature values live in the DB instead of being recomputed ad hoc.

**Strategy wiring.** `AdminWeightsPredictionStrategy` now uses `SessionFeatureComputer` for feature values instead of computing them inline.

**Feature catalog.** A migration re-labeled all 20 feature entries (name, description) for clarity (+234).

**UI polish.** Range inputs render lighter when the option hasn't been changed.

### All changes

- Added `SessionFeatureComputer` service (compute + persist feature values)
- Wired `AdminWeightsPredictionStrategy` to use it
- Re-labeled all 20 feature entries via migration
- Made unchanged range inputs visually lighter

## Lessons

Persisting computed feature values at session time moves work off the hot prediction path and gives admin strategies a stable, queryable source of truth.
