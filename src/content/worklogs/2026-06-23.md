# 23 Jun 2026

Added ESC/outside-click dismissal options and a remember-dismiss-days setting to behavora's position presets and GrapesJS editor.

## Projects

### behavora (journey-predictor-api)

**Dismissal options.** Added options for closing on outside click and ESC in position presets (+116/−3).

**Remember dismiss.** Added a "Remember dismiss days" option that only shows when "Remember dismiss" is enabled (+103/−14), and added the remember-dismiss option to the GrapesJS editor (+78/−9).

### All changes

- Added outside-click and ESC close options to position presets
- Added remember-dismiss-days setting (conditional visibility)
- Added remember-dismiss option to GrapesJS editor

## Lessons

Conditional visibility is the simplest correct form of validation for related options — "Remember dismiss days" only makes sense when "Remember dismiss" is on, so it only appears then.
