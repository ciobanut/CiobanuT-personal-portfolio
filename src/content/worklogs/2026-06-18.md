# 18 Jun 2026

Overhauled behavora banner positioning in the GrapesJS editor: a 3×3 arrow grid, margin inputs, wrapper preselect, and a cleanup pass that removed the Design & Style and positioning menus.

## Projects

### behavora (journey-predictor-api)

**Positioning.** Replaced the banner position selects with a 3×3 grid of arrow-symbol buttons (+252/−177), fixed the banner positioning in GrapesJS (+143/−54), and added "Margins around the banner" inputs (+51). Fixed the selected-button colors and changed the wrapper tag name from `main` to `div`. Auto-triggers a save when a position option is clicked or Enter is pressed.

**Editor ergonomics.** Preselect the GrapesJS wrapper on load so the Style Manager shows its properties immediately. Renamed the position sector to "Banner settings" with improved styling.

**Menu cleanup.** Removed the Design & Style menu item and its design files (−174), and the positioning menu item with its page and component (−105).

**Default banner.** Moved the default banner into the block manager as a "Temu-style Banner".

### journey-predictor-client

**Z-index.** Increased the widget z-index so the banner sits above all page elements.

### All changes

- Replaced position selects with a 3×3 arrow grid
- Fixed GrapesJS banner positioning and selected-button colors
- Added margins-around-banner inputs
- Preselect wrapper so Style Manager shows its properties
- Removed Design & Style and positioning menus
- Moved default banner to block manager as Temu-style Banner
- Increased widget z-index on the client

## Lessons

Direct-manipulation position controls (arrow grid) beat dropdowns for a spatial concept; the wrapper preselect removes the classic "why is the Style Manager empty" moment.
