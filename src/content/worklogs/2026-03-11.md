# 11 Mar 2026

Added a test-auth-header route and middleware fixes to taxi-api, and updated Bloop-landing's page table and locale handling.

## Projects

### taxi-api

**Auth header test.** Added a `test-auth-header` route to ensure the auth bearer token arrives correctly (+11/−4), using a `Request` alias for consistency. Commented out `EnsureFrontendRequestsAreStateful` middleware in the API routes and removed an unnecessary redirect after user registration (+1/−5).

### Bloop-landing

Updated the `PagesTable` columns and enhanced `PageController` locale handling (+12/−13).

### All changes

- Added test-auth-header route
- Commented out stateful-requests middleware in API routes
- Removed post-registration redirect
- Updated PagesTable + locale handling

## Lessons

A dedicated auth-header test route makes middleware/auth debugging a single curl instead of a session dance — cheap scaffolding that pays for itself.
