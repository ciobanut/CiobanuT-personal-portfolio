# 5 Mar 2026

Added `picked_up`, `dropped_off` and `expired` statuses to taxi-api ride requests, plus a ride-address section and an expiry command.

## Projects

### taxi-api

**Statuses.** Added `picked_up` and `dropped_off` statuses to ride requests and updated the flow (+86/−53). Added an `expired` status with a command to update stale requests (+48/−4).

**UI.** Added a `RideAddressSection` component to display pickup and drop-off locations (+104/−59), displayed `driver_arrives_at` in the API response when the ride is started (+3/−3), improved user prompts in `FormInput`, and removed the unused 'Find new Rides' menu item and the unused refetch prop.

### All changes

- Added picked_up/dropped_off/expired statuses
- Added expiry command for stale requests
- Added RideAddressSection component
- Displayed driver_arrives_at in response

## Lessons

A scheduled command that expires stale ride requests is the failsafe that status machines need — without it, abandoned requests linger forever.
