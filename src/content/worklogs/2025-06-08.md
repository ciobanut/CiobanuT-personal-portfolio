# 8 Jun 2025

Restricted MyPrivateOrder Filament to admins, added Sanctum tokens, and fixed the Port slug observer.

## Projects

### myprivateorder.com

**Filament access.** Made Filament accessible only to admins (+16/−1).

**Sanctum.** Added `HasApiTokens` to the user model (+2).

**Port observer.** Added `Observers\PortObserver` and fixed an error on slug generation (+33/−2), then removed the observer (+5/−36) after deciding against it.

**Config.** Updated Scout config to use `http` instead of `https` (+1).

### All changes

- Restricted Filament to admins
- Added Sanctum tokens
- Added then removed Port observer
- Fixed Scout URL scheme

## Lessons

Adding then removing an observer is a decision, not a mistake — trying the observer, finding it unnecessary, and deleting it keeps the model lean.
