# 17 Apr 2026

Added a keep-alive endpoint and heartbeat script for session management, restricted banner rendering to the owner, and hardened the display guards.

## Projects

### behavora (journey-predictor-api)

**Session keep-alive.** Implemented a keep-alive endpoint and heartbeat script for session management (+23) so active sessions stay alive without page reloads.

**Owner-only rendering.** Restricted banner rendering to the banner's owner (+77/−3) — a render can't be requested cross-tenant.

**Display guards.** Prevented showing banners already displayed to the session (+8/−5), corrected the session-based impression visibility check, and removed a debug statement from the predict method.

**Embed UX.** Added a "Copy to clipboard" button to the embed code with an updated tooltip (+64/−17), and removed the close button from the default banner HTML.

### All changes

- Added keep-alive endpoint + heartbeat script
- Restricted banner rendering to owner
- Prevented re-displaying banners to the same session
- Added copy-to-clipboard for embed code
- Removed default-banner close button

## Lessons

Multi-tenant renders must be owner-scoped at the query level, not just hidden in the UI — the +77 guard closes a real data leak.
