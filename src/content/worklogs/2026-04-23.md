# 23 Apr 2026

Added admin roles and permissions to behavora, linked the app dashboard with Filament admin, synced website selection, and added Laravel Boost MCP config.

## Projects

### behavora (journey-predictor-api)

**Admin roles.** Added an `is_admin` attribute to the `User` model with a migration (+36), and allowed admin users to view/edit/delete any banner and any website (+25).

**Dashboard ↔ admin.** Added links between the app dashboard and Filament admin (+14/−13) with a `no-wire-navigate` attribute on the Admin button.

**Website selection.** Implemented website selection synchronization and helper functions (+235/−47).

**Sidebar.** Simplified the sidebar menu structure by removing an unnecessary sub-menu (+6/−8).

**Tooling.** Added MCP configuration and guidelines for Laravel Boost (+9,996).

### All changes

- Added is_admin attribute + migration
- Admin can manage any banner/website
- Linked app dashboard ↔ Filament admin
- Synced website selection helpers
- Added Laravel Boost MCP config
- Simplified sidebar

## Lessons

A boolean `is_admin` is enough to start, but the authorization checks it enables (any banner/website) are what make it meaningful — role comes with policy, not just a flag.
