# 8 Jun 2026

Displayed the client-side banner in an iframe driven by a render URL, resizing the iframe from the dimensions the render page reports.

## Projects

### journey-predictor-client

**Render URL + iframe.** Added a render-URL state and displayed the banner in an iframe (+67/−77) — the widget loads the server-rendered banner page in a frame.

**Responsive resizing.** Resized the iframe based on the dimensions received from the render page (+85/−41), so the frame matches the banner content instead of fixed sizing.

### All changes

- Added render URL state and iframe banner display
- Resized iframe from render-page-reported dimensions

## Lessons

Iframe-based widgets are only as good as their sizing contract — letting the rendered page report its own dimensions removes the guesswork and the scrollbars.
