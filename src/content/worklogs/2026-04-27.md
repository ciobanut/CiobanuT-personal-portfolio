# 27 Apr 2026

Added the `PromptAttempt` Filament resource, fed visitor journey summaries into prompt generation, and fixed the live-period chart window.

## Projects

### behavora (journey-predictor-api)

**PromptAttempt resource.** Implemented the `PromptAttempt` resource with create, edit and list pages (+198) and enhanced its form/table with improved payload handling (+325/−41).

**Journey context.** Added a visitor journey summary to the prompt generation context and payload (+161/−11) so generated text is grounded in the visitor's actual behavior.

**Dashboard fixes.** Updated the live visitor count in dashboard analytics and fixed the chart live period to use `last_activity_at + LIVE_WINDOW_SECONDS` (+270/−65).

### All changes

- Added PromptAttempt resource (create/edit/list)
- Added journey summary to prompt generation context
- Fixed chart live-period window
- Updated live visitor count

## Lessons

Grounding LLM prompts in real journey data is the difference between generic copy and relevant copy — the summary is assembled from the same events the prediction uses.
