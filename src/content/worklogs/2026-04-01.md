# 1 Apr 2026

Added React Query for route directions and a bottom-sheet to the React Native arrival map, and enforced HTTPS with proxy trust on Bloop-landing.

## Projects

### react-native-expo

**React Query routes.** Added `@tanstack/react-query` for route directions and refactored `ArrivalMapCard` (+167/−68).

**Bottom sheet.** Added `@gorhom/bottom-sheet` and integrated it into the arrival map card (+130/−82) for a mobile-friendly detail surface.

### Bloop-landing

**HTTPS/proxy.** Enforced HTTPS in production and trusted proxies for correct URL generation (+24/−7), adjusting the Nginx HTTPS parameters and `APP_NAME`. Added a footer brand-name input to website settings.

### All changes

- Added React Query for route directions
- Integrated bottom sheet into ArrivalMapCard
- Enforced HTTPS + proxy trust on Bloop-landing
- Added footer brand name to settings

## Lessons

Enforcing HTTPS and trusting proxies must travel together — without proxy trust, secure URL generation silently breaks behind the reverse proxy.
