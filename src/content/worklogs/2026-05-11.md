# 11 May 2026

Enhanced the landing site with security headers and accessibility attributes, plus mobile fixes for the header and hero.

## Projects

### landing

**Security + accessibility.** Enhanced security headers and improved image `alt` attributes for accessibility (+49/−14). Made the hero circles semitransparent.

**Mobile fixes.** Fixed the header menu on small screens, circle opacity on mobile, and the selected-menu display (+29/−15). Fixed text wrap and rebuilt.

### All changes

- Enhanced security headers
- Improved image alt attributes
- Made hero circles semitransparent
- Fixed header menu and circles on small screens
- Fixed text wrap

## Lessons

Accessibility attributes and security headers belong in the same hardening pass — both are invisible until they matter, and cheap to add early.
