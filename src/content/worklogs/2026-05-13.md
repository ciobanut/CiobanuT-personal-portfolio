# 13 May 2026

Detected `traffic_source` in behavora's `TrackController` from the referrer URL, and fixed visitor time-spent computation.

## Projects

### behavora (journey-predictor-api)

**Traffic source.** Detect `traffic_source` in `TrackController` based on the `referrer_url` sent from the widget (+516/−14) — classifying referral traffic server-side at ingestion.

**Time spent.** Fixed visitor time-spent per session in the dashboard (+49/−96) and updated sorting keys with classes for session headers in the latest-sessions view.

**Cleanup.** Removed the widget loader for the widget in the dashboard (+0/−4).

### All changes

- Detect traffic_source from referrer_url in TrackController
- Fixed visitor time-spent per session
- Updated session header sorting keys
- Removed unused widget loader

## Lessons

Classifying traffic at ingestion (server-side, from the referrer) is more reliable than client-side sniffing — the source is known once and persisted with the session.
