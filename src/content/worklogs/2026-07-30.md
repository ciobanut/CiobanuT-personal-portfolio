# 30 Jul 2026

Major refactoring of the signal system and UI improvements.

## Projects

### myprivateorder_com

- Replaced hardcoded `SignalKey` enum with a dynamic `SignalFqn` system — signals are now identified by a fully-qualified name string, making them extensible without code changes.
- Added dark mode support across the admin panel using Tailwind's `dark:` variant.
- Implemented user presets for dashboard filters — users can now save, load, and share filter configurations.

### All changes

- Refactored SignalKey enum to SignalFqn system
- Added dark mode styles to admin panel components
- Implemented user preset CRUD operations
- Added preset sharing via URL tokens

## Lessons

A fully-qualified name system (like Java package names) is vastly more maintainable than a flat enum when the number of signal types grows beyond ~20. The upfront refactoring cost is worth it.
