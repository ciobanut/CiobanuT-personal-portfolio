# 29 Apr 2026

Integrated banner selection into behavora's prediction responses and extended the tracking fields.

## Projects

### behavora (journey-predictor-api)

**Prediction + banner.** Integrated banner selection into prediction responses (+156/−78) so a prediction carries the banner it resolves to.

**Tracking fields.** Added `page_title`, `page_type`, `referrer_url`, `clicks` and `rage_clicks` fields to tracking (+104/−9).

**Cleanup.** Updated Livewire tests to work without Volt usage and renamed variables in `PredictController` for consistency (+35/−32).

### All changes

- Integrated banner selection into prediction responses
- Added page_title/page_type/referrer_url/clicks/rage_clicks fields
- Updated tests for no-Volt usage
- Renamed PredictController variables

## Lessons

A prediction that names its banner makes the decision auditable — the response carries _what_ was chosen, not just the score.
