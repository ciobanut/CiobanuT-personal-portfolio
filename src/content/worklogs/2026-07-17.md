# 17 Jul 2026

Extracted duplicated signal computation into a shared `FeatureCalculator` on behavora, persisted intent score labels with a DB index and Eloquent scope, added avatar upload to Filament's Edit Provider, and cleaned up the forgot-password page.

## Projects

### behavora (journey-predictor-api)

**Shared FeatureCalculator.** Refactored duplicated signal computation into a shared `FeatureCalculator` class (+774/−204), so session, event and scoring paths compute features once.

**Intent score labels.** Persisted the intent score label on `Predictions` with a DB index and an Eloquent scope (+113), and surfaced it across the UI: recent events, session statistics, and the latest sessions view. Refactored intent label handling into a dedicated badge component.

**Scoring breakdown.** Implemented a scoring breakdown feature with detailed display and refresh functionality (+146), redesigned the card with Tailwind/DaisyUI, and added a button linking to the scoring rules page. Extracted score-range config and removed the redundant `normalizeSegment`.

**Threshold consistency.** Fixed the show-threshold so all three components (scoring-rules, edit-banner-threshold, modal) share the same behavior.

### myprivateorder.com

**Provider avatar upload.** Added avatar upload to Filament's Edit Provider (+986/−781) with a profile image storage doc (+258). Removed Alpine from the forgot-password page (Livewire only) and fixed the countdown to start right after submitting the email, not after refresh.

### astro-portfolio-website

Fixed a build failure in `Metrika.astro` ("Unexpected default") and gitignored temp images and Serena config.

### behavora-demo

Added an `EnvBadge` component with an env-aware link in the top-left corner.

### All changes

- Extracted shared `FeatureCalculator` (+774/−204)
- Persisted intent score labels with DB index + scope; surfaced in sessions/events/stats
- Added scoring breakdown feature with refresh; linked to scoring rules
- Made show-threshold consistent across three components
- Added provider avatar upload to Filament Edit Provider
- Removed Alpine from forgot-password; fixed countdown start
- Fixed Metrika.astro build failure

## Lessons

Computing features once in a shared calculator removes the classic drift where session stats and scoring rules disagree about a signal's value.

A DB index plus an Eloquent scope makes a persisted label cheap to query everywhere the dashboard needs it.
