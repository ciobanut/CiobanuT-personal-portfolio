# 28 Jul 2026

Added full CRUD for SignalPreset on behavora (Filament resource, pages, form) and extended the MyPrivateOrder registered-users widget with provider bio stats.

## Projects

### behavora (journey-predictor-api)

**SignalPreset CRUD.** Implemented complete CRUD for `SignalPreset` as a Filament resource with pages and a form (`feat(signal-presets): add CRUD functionality for SignalPreset with resource, pages, form`, +348). Fixed the rules display inside `SignalPresetForm` and `SignalPresetsTable` so configured signal rules render correctly.

**Docs.** Updated the README with installation instructions for Filament assets.

### myprivateorder.com

**Provider bio stats.** The registered users widget now shows stats for providers with and without a bio, giving a quick view of profile completeness.

### All changes

- Added `SignalPreset` Filament resource with pages and form (CRUD)
- Fixed signal rules display in `SignalPresetForm` / `SignalPresetsTable`
- Updated README with Filament asset install instructions
- Added provider with/without bio stats to registered users widget

## Lessons

Rules-style sub-resources (a preset holding many signal rules) read far better in a dedicated form than in a generic table — the CRUD landed after the display fix showed what the shape should be.
