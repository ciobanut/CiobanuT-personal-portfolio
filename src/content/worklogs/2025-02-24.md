# 24 Feb 2025

Added Traefik with HTTPS redirects to the MyPrivateOrder deploy, pushed images to GHCR, and enabled HTTP/3.

## Projects

### myprivateorder.com

**Traefik + HTTPS.** Added Traefik and docker push to GitHub (+92/−33), then iterated heavily on HTTPS: www→non-www redirects (+10/+18), permanent redirects, `entrypoints=https`, and Cloudflare SSL. Added HTTP/3 support (+3/+2).

**Deploy pipeline.** Added a `docker pull` step (+3), GHCR_TOKEN handling, `--no-cache` builds, and `git clone --depth=1`. Replaced `:latest` with explicit tags (+6).

### All changes

- Added Traefik with HTTPS redirects
- Pushed images to GHCR with explicit tags
- Enabled HTTP/3
- Added docker pull step
