# 23 Jan 2026

Fixed campaign influencer date-range validation in Bloop-API, added tests, and updated the changelog.

## Projects

### Bloop-API

**Validation.** Corrected the HTTP method for campaign influencer date-range validation (+1/−1), allowed the service end date to equal the start date (+3/−2), and added a test for a successful campaign store with the same start and end dates (+21).

**Coverage.** Added assertions for campaign offer creation in the success case (+17) and fixed the version number in `CHANGELOG.md`.

### All changes

- Fixed date-range validation method
- Allowed end date equal to start
- Added same-date campaign test + offer creation assertions
- Updated CHANGELOG

## Lessons

Boundary tests (start === end) are where date-range validation usually breaks — the "equal to" rule and its test landed together deliberately.
