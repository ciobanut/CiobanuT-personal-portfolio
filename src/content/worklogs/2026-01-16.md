## Projects

### behavora (journey-predictor-api)

**Session validation.** Refactored session validation and feature tracking in the API session tracker (+172/−141).

**API structure.** Migrated API controllers to a `v1` namespace and updated the API routes (+9/−9).

### All changes

- Added feature weights via BannerFeature model
- Enhanced widget scoring logic
- Refactored session validation/tracking
- Migrated API controllers to v1 namespace
