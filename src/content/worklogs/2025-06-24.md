# 24 Jun 2025

Updated the create-provider API with validation and publishing on MyPrivateOrder.com, and optimized the Dockerfile to three stages.

## Projects

### myprivateorder.com

**Provider API.** Updated the create-provider API (+15/−7), fixed its validation rules (+25/−27), added provider publishing (+12), and scraped only ports that don't already have taxis (+3/−8).

**Dockerfile.** Moved `contactHelpers.php` from `autoload-dev` to `autoload` (+5), built a 3-stage Dockerfile (+18/−29), installed Composer in the final container (+28), and ran a composer update (+268/−251).

### All changes

- Updated create-provider API + validation + publish
- Scraped only ports without taxis
- Built 3-stage Dockerfile with composer in final stage

## Lessons

A 3-stage Dockerfile (build → vendor → runtime) shrinks the image and keeps secrets out of the runtime layer — the composer stage is where that trade lives.
