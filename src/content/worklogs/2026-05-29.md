# 29 May 2026

Built the auto_sender dashboard, finished the maryUI migration, renamed `keyword_id` to `job_keyword_id`, and extended Bloop-API's chat response with `service_id` and the influencer ID.

## Projects

### auto_sender

**Dashboard.** Implemented the dashboard (+6,541/−65) and cleaned up before the build (+249/−426). Added a design doc and updated the agent doc to use maryUI.

**MaryUI migration.** Replaced all Flux components with maryUI (+1,612/−636) and hardcoded tabler icons with the `blade-tabler-icons` package (+104/−478).

**Naming.** Renamed `keyword_id` to `job_keyword_id` across models, factories and references (+93/−42).

**Review app.** Updated references to `selectedLetter` with `$this->` for consistency in the review flow.

### Bloop-API

**Chat response shape.** Added `service_id` to the campaign-task detail response and updated the test. Returns the influencer ID associated with the chat in the advertiser chat response, and added a missing top-level `data` wrapper to the 200-response schema (+121/−80).

**Debug.** Added logs when a media file isn't found on disk during zip creation.

### All changes

- Implemented auto_sender dashboard
- Replaced Flux → maryUI; icons → blade-tabler-icons
- Renamed keyword_id → job_keyword_id
- Added service_id + influencer ID to Bloop chat responses
- Added media-file-missing debug logs
