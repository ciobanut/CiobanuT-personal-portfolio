Implemented a `useInfiniteChat` hook with auto-scroll in stream-front, added dynamic viewer counts, and refined login and avatars.

## Projects

### stream-front

**Chat.** Implemented a `useInfiniteChat` hook for dynamic message display (+75/−37) and enhanced `StreamChat` with auto-scroll and new message count (+59/−7).

**Viewers.** Implemented dynamic viewer counts for video streams (+16/−3) and updated the display in Home and `StreamChat` components (+34/−8).

**Login.** Returned the login and styled it exactly as designed in Figma (+9/−8); replaced button elements with a custom `Button` component in `AuthModal` (+11/−10).

**Media.** Added new video thumbnails and live-streamer avatars (+30/−18, +13/−13), updated the video container aspect ratio for the homepage video (+2), and fixed avatars on the streams page.

### All changes

- Implemented useInfiniteChat + auto-scroll
- Added dynamic viewer counts
- Styled login per Figma; Button component
- Added video thumbnails and avatars

## Lessons

Infinite chat needs two things: a pagination hook (useInfiniteChat) and a scroll-anchoring strategy so new messages don't yank the user's position.
