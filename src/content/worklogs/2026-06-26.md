# 26 Jun 2026

Extracted behavora's banner preview and settings into reusable components on every banner page, fixed settings refresh after save, and refactored client-side dismissal-option handling.

## Projects

### behavora (journey-predictor-api)

**Reusable preview/settings.** Extracted banner preview and banner settings into components and inserted them on all banner pages (+300/−118) — one source of truth for the banner chrome. Moved dismiss options from the editor page into the UX & Behavior area.

**Refresh fix.** Fixed banner display-settings refresh after save using a dynamic `wire:key`, so a saved change re-renders the panel immediately (+17/−117).

**Badges.** Replaced the banner settings table view with a list of badges (+17/−29).

**Docs.** Added Banner Settings progress doc and removed unnecessary files (+121/−2261).

### journey-predictor-client

**Dismiss refactor.** Moved the search for dismiss options (ESC, outside click, remember) out of the server-rendered path into a shared lookup (+64/−389).

### All changes

- Extracted banner preview + settings components onto all banner pages
- Moved dismiss options to UX & Behavior
- Fixed settings refresh after save with dynamic `wire:key`
- Replaced settings table with badges
- Refactored client dismissal-option lookup

## Lessons

Reusable chrome components eliminate the drift where each banner page renders preview/settings slightly differently.
