# 13 Jul 2026

Reworked behavora's banner management (new index page, route cleanup, date validation), made the Impressions card show real counts, and added a delete-with-confirmation flow for websites.

## Projects

### behavora (journey-predictor-api)

**Banner management.** Updated banner routes and views to manage banners, including a new index page and route layout (+145/−57). The save button is now fixed bottom-right and always visible.

**Date validation.** Banner start dates no longer accept past days, and end dates can't be earlier than start (+134). Removed the hard-coded "temu" from a banner name and the static countdown.

**Render behavior.** A banner now shows on the render page even when it isn't active — useful for previewing inactive designs.

**Real impressions.** Fixed the "Banner Impressions" card on My Websites to use actual impression counts instead of placeholder data.

**Website deletion.** Added delete functionality for websites behind a confirmation input (`modal-settings`), so the name must be typed to confirm.

### All changes

- New banner index page and reorganized routes/views
- Added start/end date validation on banners
- Show banners on render page even when inactive
- Wired Banner Impressions card to real counts
- Added delete-with-confirmation for websites
- Fixed save button to be always visible

## Lessons

Date-range validation belongs at the form boundary, not spread across views — one commit covered start-not-in-past and end-not-before-start together.

Hard-coded names/countdowns in seed data quietly leak into production banners; the removal commit is the cleanup that follows.
