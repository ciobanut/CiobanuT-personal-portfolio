# 29 Mar 2026

Added `MapTrackingCard` and `ArrivalMapCard` with route polylines to the React Native Expo app, plus reusable UI components.

## Projects

### react-native-expo

**Map cards.** Implemented `MapTrackingCard` (+931) with `Badge`, `Image` and `Toast` components, and integrated it into `HomeScreen`. Added `ArrivalMapCard` and wired it into `HomeScreen` (+103/−104), then refactored it to use `MapView` directly (+20/−29), display the route with a `Polyline` (+54/−4), and conditionally render a map or image with a web fallback (+106/−34). Adjusted `DriverArrived` integration.

**Housekeeping.** Updated dependencies and improved UI components (+2,424/−1,353).

### All changes

- Implemented MapTrackingCard with Badge/Image/Toast components
- Added ArrivalMapCard with polyline route + map/image fallback
- Integrated both into HomeScreen
- Updated dependencies

## Lessons

Building map cards against `MapView` directly (with a static-image fallback) keeps the feature usable offline and on web — a pragmatic hybrid instead of one render path.
