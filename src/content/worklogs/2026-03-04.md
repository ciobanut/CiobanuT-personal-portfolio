# 4 Mar 2026

Added a `ready_to_pickup` status to taxi-api ride requests, seeded a Filament admin user, and fixed local Filament after a Livewire publish issue.

## Projects

### taxi-api

**Ready to pickup.** Added the `ready_to_pickup` status to ride requests and the new pickup flow (+278/−261).

**Filament fix.** Fixed local Filament after a `php artisan livewire:publish` issue (+23,744/−1,293 — the published assets re-commit) and added a Filament admin user to the seeder (+149/−138).

**Details.** Enhanced ride request details with participants and updated the active ride panel (+20/−7).

### All changes

- Added ready_to_pickup status + pickup flow
- Fixed local Filament assets
- Seeded Filament admin user
- Enhanced ride request details with participants

## Lessons

`livewire:publish` writing into the repo is a trap — the giant ±commit is published assets landing in version control; pinning which assets are published keeps it reviewable.
