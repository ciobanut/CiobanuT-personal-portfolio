# 17 Feb 2026

Migrated taxi-api components and pages to TypeScript, refactored auth into a `useAuthContext` hook, and made registration transactional.

## Projects

### taxi-api

**TypeScript migration.** Migrated components and pages to TypeScript, updating routing and layout (+83/−61), migrating auth and user-management components (+258/−339), and migrating ride-related types and components (+18/−22). Removed `"use client"` directives from multiple components (+24/−36) and dropped unused `VITE_PUBLIC_API_BASE_URL` env vars.

**Auth refactor.** Refactored the authentication context and hooks to use `useAuthContext` (+28/−34), refactored navigation and auth handling (+58/−73), and enhanced logout with promise handling and a global route (+20/−10).

**Registration.** Implemented a database transaction for the user registration process (+22/−17) and simplified the store method in `RegisteredUserController` (+10/−8).

### All changes

- Migrated components/pages to TypeScript
- Refactored auth context to useAuthContext
- Made registration transactional
- Removed use-client directives and unused env vars

## Lessons

A full TypeScript migration is best done as a series of focused commits (auth, rides, layout) rather than one giant rewrite — each stays reviewable.
