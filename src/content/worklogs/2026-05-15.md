# 15 May 2026

Added a banner-shown sessions filter to behavora, fixed `time_spent` sorting, and widened the `page_url` column.

## Projects

### behavora (journey-predictor-api)

**Session filters.** Added a filter to display only sessions where a banner was shown (+306/−163) and fixed sorting in the sessions table.

**Time sort.** Fixed sorting by `time_spent` in the sessions table and updated the profile page (+142/−77).

**Column width.** Changed the `page_url` type in the `visitor_journeys` table so longer URLs can be saved (+28).

### All changes

- Added banner-shown sessions filter
- Fixed time_spent sorting; updated profile page
- Widened page_url column in visitor_journeys

## Lessons

Filtering on an outcome (banner shown) is the analytics view users actually ask for — the dashboard becomes answerable instead of a data dump.
