# 18 Mar 2026

Added full i18n support (English/Russian/Romanian) to taxi-api, implemented a support ticket system with CRUD and enums, and redesigned the login with animated taxis.

## Projects

### taxi-api

**i18n.** Added i18n support with translations for English, Russian and Romanian (+1,568/−853), plus missing RU/RO translations for authentication and other flows (+218/−8).

**Support tickets.** Implemented the support ticket system with CRUD operations and enums for status/type (+443/−1), added the support ticket page with a form and API integration (+255), and refactored the resource actions and OpenAPI annotations (+88/−80).

**Login.** Added animated floating taxis to the login page (+53/−5), a `Logo` component integrated into Auth and Support Tickets pages (+97/−79), improved error handling and user state in `SupportTicketsPage`, and updated pricing constants for the base rate and minimum fare.

### All changes

- Added i18n (EN/RU/RO) translations
- Implemented support ticket CRUD + enums + page
- Added animated floating taxis and Logo component
- Improved error handling and pricing constants

## Lessons

i18n is a cross-cutting addition — the +1,568 initial commit and the follow-up translation commit show the effort to reach three languages without breaking existing views.
