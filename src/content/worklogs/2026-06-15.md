# 15 Jun 2026

Added an action-target column to behavora's Recent Events, surfaced prediction-mode settings in the modal, and updated the embed script URLs.

## Projects

### behavora (journey-predictor-api)

**Action target.** Added an `action_target` column to the "Recent Events" table in session details, and combined the Event type column with the action target so each row shows both.

**Prediction mode.** Added prediction-mode settings to the modal and updated the available options; predictions are now saved when `AdminWeightsPredictionStrategy` is selected too.

**Embed script.** Updated the embed script with new dev CDN and API URLs (production uses `data-api`).

**Cleanup.** Removed unused website settings from the validator and modal components (+3/−135).

### behavora-demo

**Docs.** Updated the README and Environment component with local development instructions.

### All changes

- Added action-target column to Recent Events
- Combined event type column with action target
- Save predictions when AdminWeights strategy selected
- Added prediction-mode settings to modal
- Updated embed script dev/prod URLs
- Removed unused website settings
- Updated demo README and env component

## Lessons

Unused validator and modal settings accumulate faster than they're noticed — the −135 cleanup commit shows the value of removing them when a feature takes a different shape.
