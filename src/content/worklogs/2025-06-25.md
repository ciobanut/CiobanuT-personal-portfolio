Ensured the MyPrivateOrder API request categories are always an array.

## Projects

### myprivateorder.com

**API hardening.** Ensured that API request `categories` is an array (+20/−17) so a single value or missing field doesn't break downstream filtering.

### All changes

- Normalized categories to array in API request

## Lessons

"Always an array" is a cheap contract that prevents a whole class of shape bugs — single-value input coerced at the boundary.
