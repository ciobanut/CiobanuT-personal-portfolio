# 27 Feb 2026

Added an `ActiveRideRequest` interface with active ride fetching, a Google Maps navigation button, and ETA display to the taxi-api driver dashboard.

## Projects

### taxi-api

**Active ride.** Added an `ActiveRideRequest` interface and implemented active ride fetching (+177/−39). Updated `ActiveRidePanel` and `DriverDashboardPage` to pass `rideId` for the active ride (+22/−15) and drafted `driverRideStart` to initiate a ride in the API (+13).

**Google Maps.** Added a Google Maps navigation button to `ActiveRidePanel` (+86) that opens the drop-off in Google Maps, and fixed navigation parameters on "Open in Google Maps".

**Pools/ETA.** Enhanced `RidePoolCard` to accept an estimated time to the client (+42/−7), adjusted the active ride panel's responsive styles, and refined DriverHeader/DriverDashboard typography.

### All changes

- Added ActiveRideRequest + active ride fetching
- Added Google Maps navigation button
- Enhanced RidePoolCard with ETA
- Refined responsive styles and typography

## Lessons

An "open in Google Maps" button is a small integration that makes the panel genuinely useful — navigation is one tap away from the active ride.
