# 3 Jul 2026

Added timezone auto-detection to behavora's display timing, made settings conditionally visible, and hardened the public banner render endpoint against abuse.

## Projects

### behavora (journey-predictor-api)

**Timezone support.** Added timezone selection with auto-detection and IANA support to display timing settings (+40) — schedules now evaluate in the visitor's timezone.

**Conditional settings.** Display timing fields (rule, frequency, etc.) are now shown conditionally, and dismissal settings toggles/inputs reveal only when relevant.

**Public endpoint hardening.** Secured `BannerController::render` with rate limiting (+180/−15) so a public render endpoint can't be hammered.

**Preview cleanup.** Cleaned up iframe error handling and improved readability in the preview view (+46/−70).

### All changes

- Added timezone selection with auto-detection + IANA in display timing
- Made display timing and dismissal settings conditionally visible
- Rate-limited the public `BannerController::render` endpoint
- Cleaned up iframe error handling in preview

## Lessons

Public render endpoints are untrusted surfaces — rate limiting belongs there by default, not after an incident.
