# 10 Mar 2026

Implemented multilingual page management with CRUD and slug caching on Bloop-landing, plus the landing page layout template.

## Projects

### Bloop-landing

**Page management.** Added page management functionality with CRUD operations and admin UI (+290/−0). Enhanced it with unique slug validation, improved seeds and an `is_published` toggle in the correct form group.

**Multilingual.** Implemented multilingual support for pages in Filament with locale tabs (+293/−66), added an `activeLocaleTab` property with enhanced translation handling (+65/−12), and added locale-specific unique indexes with refactored slug caching (+69/−23). Prevented auto-changing the slug when editing a title if the slug is saved.

**Layout.** Added the landing page layout template (+2,481/−2) and replaced the landing page layout with a new component-based structure (+21/−26).

### All changes

- Added page CRUD + admin UI
- Implemented multilingual pages with locale tabs
- Added slug caching + locale unique indexes
- Added landing page layout template

## Lessons

Slug caching with locale-specific unique indexes is the crux of multilingual pages — same slug per locale is valid, duplicates within a locale are not, and the cache must invalidate on slug changes.
