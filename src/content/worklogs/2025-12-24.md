# 24 Dec 2025

Added purgeCSS to the landing theme, reorganized CSS, integrated Google Tag Manager from the Voyager admin, and fixed CSP/HTML validation.

## Projects

### landing

**PurgeCSS.** Added purgeCSS and implemented it in the `soft.cy` theme to remove unused styles (+375/−1,937) and moved CSS from `public` into `app.css` (+1,971).

**GTM.** Integrated the Google Tag Manager script from the Voyager admin settings (+1/−16), making gtag use the ID from the admin.

**SEO/accessibility.** Added SEO meta tags from dashboard settings to the homepage (+3), fixed CSP to include `connect-src` for Google Analytics, fixed HTML errors on all pages (+18/−18) and w3c validation requirements (+418/−423), and made footer contacts clickable.

### All changes

- Added purgeCSS (−1,937 unused CSS removed)
- Moved CSS to app.css
- Integrated GTM from Voyager admin
- Fixed CSP, HTML validation, footer links

## Lessons

PurgeCSS is the one-line win that drops megabytes of unused CSS — the −1,937 is framework cruft the theme never used.
