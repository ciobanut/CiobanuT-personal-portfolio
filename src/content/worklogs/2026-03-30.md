# 30 Mar 2026

Implemented Bloop-landing's support ticket system with Honeypot spam protection, a cookie consent banner, and dynamic website settings labels.

## Projects

### Bloop-landing

**Support tickets.** Implemented the support ticket system with form, controller and Filament resource (+539/−3).

**Spam protection.** Integrated Spatie Honeypot for spam protection in the support ticket form (+218/−141).

**Consent + scripts.** Added a cookie consent banner and integrated custom scripts (+176/−4).

**Settings UX.** Implemented dynamic labels and descriptions for website settings across the UI (+258/−102). Updated images to AVIF for performance and commented out a temporarily-unneeded Settings section.

### All changes

- Implemented support ticket system (+539)
- Added Spatie Honeypot spam protection
- Added cookie consent banner + custom scripts
- Made website settings labels dynamic
- Switched images to AVIF

## Lessons

A public form (support tickets) is a spam magnet — Honeypot is the cheap first line before any CAPTCHA, and it pairs naturally with a Filament-backed resource for the queue.
