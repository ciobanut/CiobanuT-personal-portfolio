# 8 May 2026

Added cookie consent management with conditional analytics loading to MyPrivateOrder.com, and enhanced the landing contact form with service selection.

## Projects

### myprivateorder.com

**Cookie consent.** Added cookie consent management and analytics script loading (+909/−13) — scripts load only after the visitor consents. Added Alpine.js as the consent UI runtime.

### landing

**Contact form.** Enhanced the contact form to include service selection and updated the lead model accordingly (+147/−118).

**Image component.** Updated `img-text-section` to support `image_svg` and removed unused code (+11/−58).

### All changes

- Added cookie consent management + conditional analytics loading
- Added Alpine.js for consent UI
- Added service selection to landing contact form; updated lead model
- Added image_svg support to img-text-section

## Lessons

Consent-gated loading is a script-loading concern, not a page concern — the consent state decides which scripts initialize, and that logic lives in one place.
