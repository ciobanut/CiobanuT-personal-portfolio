# 16 Jun 2026

Removed two unused behavora pages, made the frontend build safe without a REVERB key, fixed a referrer overflow, and cleaned the built assets out of git.

## Projects

### behavora (journey-predictor-api)

**Page cleanup.** Deleted the "Content & Text" and "Analytics & Tracking" pages (−192) — features that never shipped as real pages.

**Build safety.** Protected `echo.js` from breaking the entire build when `VITE_REVERB_APP_KEY` is missing (+11/−9), and added the `VITE_REVERB_*` variables to GitHub Actions for the `npm run build` step so websocket config reaches the frontend build.

**Git hygiene.** Removed the `public/build` folder and added it to `.gitignore` (−788).

**Fixes.** Fixed the badge warning color and resolved a `Data too long for column 'referrer'` error when tracking very long referrer URLs (+28/−31). Updated prediction strategy labels for clarity in modal settings.

### All changes

- Deleted Content & Text and Analytics & Tracking pages
- Protected echo.js when REVERB key missing; added REVERB vars to CI build
- Removed public/build from git
- Fixed badge warning color
- Fixed referrer column overflow on long URLs
- Updated prediction strategy labels

## Lessons

Builds must degrade gracefully when a runtime env var is absent — a missing REVERB key shouldn't take down the whole asset pipeline.

Long referrer URLs are an unbounded input on an unbounded column; the fix caps what gets stored.
