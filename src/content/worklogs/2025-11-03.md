# 3 Nov 2025

Enhanced the MyPrivateOrder provider bio with a RichEditor and a 100k character limit, displayed services on the provider view, and added a user_id check.

## Projects

### myprivateorder.com

**Bio.** Replaced the bio text input with a RichEditor (+6/−3), raised the bio character limit to 100,000 in the update method (+1), and made the providers table allow a nullable longText bio (+27).

**Provider view.** Enhanced the provider details view by adding a services display (+25/−29).

**API.** Added a `user_id` check in the provider API (+12).

### All changes

- Replaced bio input with RichEditor; 100k limit
- Displayed services on provider view
- Added user_id check to provider API

## Lessons

Rich text bios need schema headroom (longText) and a generous limit — the 100k cap matches a WYSIWYG editing model.
