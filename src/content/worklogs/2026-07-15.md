# 15 Jul 2026

Updated behavora's UI stack (latest maryUI, daisyUI 5.6), fixed Safari 17+ dialog backdrop-filter, and extended the GrapesJS banner editor.

## Projects

### behavora (journey-predictor-api)

**UI stack updates.** Updated maryUI to the latest version (+793/−803) and daisyUI to 5.6. These bring API/class changes that ripple through components.

**Safari dialog fix.** Added a Safari 17+ `backdrop-filter` fix for `dialog` elements so blurred backdrops render correctly.

**GrapesJS editor.** Added a video block to the basic components and fixed invisible checkboxes.

### All changes

- Updated maryUI to latest (+793/−803)
- Updated daisyUI to 5.6
- Added Safari 17+ backdrop-filter fix for dialogs
- Added video block to GrapesJS basic components
- Fixed invisible checkboxes

## Lessons

Component-library upgrades are high-churn, low-logic commits — the value is staying current, and the cost is review noise. Batch them on quiet days.
