# 23 Mar 2026

Added `grapes-init.js` to behavora's Vite input array so the banner editor ships in the build, unified auth/profile styles, and updated the landing page to the new design.

## Projects

### behavora (journey-predictor-api)

**Build fix.** Added `grapes-init.js` to the Vite input array so it's included in the production build (+945/−2) — the banner editor script was being dropped from the bundle.

**Styles.** Updated styles for consistency across authentication and profile pages (+60/−50).

**Leads.** Updated the leads `store` method to return a `JsonResponse` and refactored the lead handling (+5/−4).

**Embed.** Fixed the embed-code URL for the journey-predictor widget.

### Bloop-landing

Modified the landing page according to the new design (+274/−246), updated the feature-section layout with download links for influencers, and added favicon + web manifest files.

### All changes

- Added grapes-init.js to Vite input (+945)
- Unified auth/profile styles
- Leads store returns JsonResponse
- Updated landing per new design
- Added favicon and web manifest

## Lessons

A script missing from the Vite entry array is a silent production bug — the feature works in dev (where Vite finds it) and vanishes in the build. Entry arrays deserve a checklist.
