# 13 Apr 2025

Ran the Typesense Scout import, opened its port, and switched avatar uploads to streaming.

## Projects

### myprivateorder.com

**Typesense.** Ran `scout:import "App\Models\Port"` (+4), opened port 8108 for Typesense (+7/−5), and fixed a 504 error with the API key config.

**Avatar.** Refactored `UploadAvatar` to use `addMediaFromStream` instead of `addMediaFromUrl` (+2/−1) and added the `fileinfo` PHP extension in the Dockerfile (+1) so stream uploads work.

### All changes

- Imported Ports into Typesense via Scout
- Opened Typesense port 8108
- Switched avatar upload to streaming

## Lessons

Stream-based uploads are more reliable than URL-fetching — the refactor removes a whole class of "URL not reachable from the server" failures.
