# 9 May 2026

Removed deprecated Ansible configurations from MyPrivateOrder.com and consolidated Alpine.js into the Livewire-bundled copy.

## Projects

### myprivateorder.com

**Ansible cleanup.** Removed deprecated Ansible configurations and extensions (−713).

**Alpine dedup.** Removed Alpine.js installed separately from Livewire (+1,196/−913) — Livewire already bundles its own Alpine, so the extra copy was dead weight and a version-drift risk.

**Checkpoints.** Two PI checkpoint commits recorded mid-day state.

### All changes

- Removed deprecated Ansible configs
- Removed separately-installed Alpine.js
- Two checkpoint commits

## Lessons

Duplicated runtime libs (Alpine via Livewire + standalone) drift in behavior and bloat the bundle — the −913 commit resolves the ambiguity in favor of the bundled copy.
