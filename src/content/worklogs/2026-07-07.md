# 7 Jul 2026

Renamed two behavora banner settings to be self-describing and consistent across the codebase.

## Projects

### behavora (journey-predictor-api)

**`auto_hide_after_sec`.** Renamed the `duration_ms` variable to `auto_hide_after_sec`, moving it to a single source so the value's unit and meaning are explicit.

**`trigger`.** Renamed the banner settings variable from `display_rule` to `trigger` (+11/−20), matching how the field is actually used.

### All changes

- Renamed `duration_ms` → `auto_hide_after_sec`
- Renamed `display_rule` → `trigger`

## Lessons

Naming is a contract: a field named `duration_ms` hides its unit in the suffix, and `display_rule` described an implementation shape rather than intent. Both renames cost one focused commit while the codebase is small.
