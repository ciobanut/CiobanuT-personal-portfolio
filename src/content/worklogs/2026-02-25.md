# 25 Feb 2026

Implemented `GetDriverProfile` and `GetDriverLocation` APIs on taxi-api, added an estimated-drive-time helper, and seeded ride pools.

## Projects

### taxi-api

**Driver APIs.** Implemented `GetDriverProfile` (+138/−29) and wired it into `DriverDashboardPage`, enhanced the `DriverProfileResponse` type with additional user details (+8), and implemented `GetDriverLocation` with location retrieval (+50/−7).

**Estimates.** Added an `estimateDriveTimeMinutes` helper and updated `estimatedDuration` (+9/−1).

**Seed.** Created a `RidePoolSeeder` to seed ride pools and their ride requests (+35/−19), and fixed the redirect route in `AuthenticatedSessionController`.

### All changes

- Implemented GetDriverProfile + GetDriverLocation APIs
- Added estimateDriveTimeMinutes helper
- Created RidePoolSeeder
- Fixed post-auth redirect

## Lessons

Seeded pools give the driver dashboard real data to develop against — the seeder commits the fixture that every subsequent UI commit depends on.
