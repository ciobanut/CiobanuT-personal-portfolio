# 30 Jun 2026

Fixed behavora's null banner-settings error, prevented Docker from injecting `.env` into images, and documented local dev setup.

## Projects

### behavora (journey-predictor-api)

**Null-safe settings.** Fixed an error that occurred when banner settings were `null`, so the UI degrades gracefully instead of crashing.

**Docker hygiene.** Prevented Docker from injecting `.env` into the container build — env belongs at runtime, not baked into the image.

**Dev docs.** Added local development setup instructions covering both Docker and native methods (+110).

### All changes

- Fixed null banner-settings error
- Prevented Docker from injecting `.env` into builds
- Added local dev setup docs (Docker + native)

## Lessons

Null-guarding persisted settings at the boundary is cheaper than chasing "works for new rows, crashes for old" bugs.

Baking `.env` into an image is a supply-chain smell — runtime env keeps the image reusable across environments.
