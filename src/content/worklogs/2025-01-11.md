# 11 Jan 2025

Added the Flysystem AWS S3 driver to MyPrivateOrder and debugged the avatar upload path.

## Projects

### myprivateorder.com

**S3 driver.** Added `league/flysystem-aws-s3-v3` (+275/−1) as the S3 filesystem driver.

**Avatar debugging.** Debugged the avatar upload — removing validation to isolate the failure (+2), testing the upload (+1), and fixing `uploadAvatar` (+1). Reverted `bootstrap/app` edits that didn't help (+9/+3) and tuned the Livewire config for uploads (+14/−7).

### All changes

- Added Flysystem AWS S3 driver
- Debugged avatar upload (validation, config)

## Lessons

S3 uploads involve storage driver + Livewire config + validation — isolating each variable is the only way to find the failing layer.
