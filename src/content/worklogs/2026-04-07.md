Implemented behavora's personal banner sending feature with modal and rendering, plus a no-banners state.

## Projects

### behavora (journey-predictor-api)

**Personal banner send.** Implemented the personal banner sending feature with a modal and banner rendering (+100/−6) — an operator can send a specific banner to a specific session.

**No-banners state.** Enhanced the feature with a no-banners state and improved messaging (+47/−18).

**Migration.** Moved the `last_activity_at` column into a new migration so it doesn't cause problems (+28/−1).

### All changes

- Implemented personal banner sending with modal
- Added no-banners empty state
- Moved last_activity_at to its own migration

## Lessons

Splitting columns into their own migrations makes rollbacks surgical — a late-added column should never hold up the migration it was bolted onto.
