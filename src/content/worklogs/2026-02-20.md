# 20 Feb 2026

Refactored taxi-api driver dashboard components with a `RidePoolCard`, added model factories, and extracted location handling.

## Projects

### taxi-api

**Dashboard refactor.** Refactored the driver dashboard components and implemented `RidePoolCard` (+646/−139). Updated `RidePoolResource` to handle user relation loading (+27/−21).

**Factories.** Added factories for `Driver`, `RidePool` and `RideRequest` models (+276/−8) and enhanced the related factories.

**Location extraction.** Extracted location handling and ride-request fetching from components into a shared spot (+83/−109), removing an unused import.

### All changes

- Implemented RidePoolCard; refactored driver dashboard
- Added Driver/RidePool/RideRequest factories
- Extracted location handling + ride request fetching

## Lessons

Model factories are the prerequisite for realistic seeds and tests — the +276 seeds a whole pool ecosystem instead of hand-built fixtures.
