# 31 May 2026

Converted auto_sender's Livewire components to the maryUI code-first (`--mfc`) pattern, renamed `index` components meaningfully, and polished the sidebar and fonts.

## Projects

### auto_sender

**MaryUI conversion.** Converted all remaining Livewire components to the `--mfc` (maryui code-first) pattern: the settings group (+26/−160), the pipeline group (+26/−70), and the rest (+85/−145). Renamed components from `index` to relevant names across the codebase.

**Sidebar.** Highlighted the active page in the sidebar menu (+146/−98) and fixed logout.

**Titles.** Removed page titles set via `Livewire\Attributes\Title`.

**Fonts.** Replaced Instrument Sans with Google Sans Flex, then Google Sans Flex with Fustat.

### All changes

- Converted settings, pipeline and remaining Livewire components to `--mfc`
- Renamed index components to relevant names
- Highlighted active page in sidebar; fixed logout
- Removed Livewire Title attributes
- Swapped fonts (→ Google Sans Flex → Fustat)

## Lessons

A code-first UI convention (`--mfc`) makes component styles explicit and inspectable; the migration touched every group, so doing it per-group kept each diff reviewable.
